What works today

The pre-alpha library covers one authenticated WAP-199 UDP profile with RSA, 3DES-CBC-EDE, and full SHA. It handles full and resumed handshakes, protected records, key refresh, and closure.

Live evidence. BlackBerry 7290 verified the Rust gateway. The separate KWTLS runs exercised authenticated DES-CBC with the same historical client.

Open work. Independent gateway verification for the Rust client on the exact supported suite is still open.
